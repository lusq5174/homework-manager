应用简介

作业管理器（课堂端）是一款面向教室大屏与课堂场景的班级作业管理工具，支持单个云班级绑定、作业展示与课堂使用。

详细介绍见使用说明文档

更新日志

v3.1.0 2026-09-13
新增功能
  • 新增「作业管理器（本地）」独立版本
  • 教师端、课堂端新增「云端作业变更冲突检测」
  • 更新提示弹窗新增 Gitee 备用下载地址，便于 GitHub 访问缓慢时下载
修复与优化
  • 教师端批量布置容错增强

  • 预览作业等减少 innerHTML 拼接，增强转义与安全性
  • 降低多人/多端同时编辑同一班级时，后保存无提示覆盖云端内容的风险
  • 修复其他已知问题，提升使用稳定性

云端作业已更新

当前班级的云端作业已被修改，而你正在编辑作业，界面中显示的内容仍是修改前的版本。
· 如果继续保存，将会覆盖云端的最新内容。
· 建议刷新页面后重新编辑，以免丢失他人的修改。

保存前检测到云端变更

准备上传时重新读取了云端数据，发现当前班级的作业在你编辑期间已被修改。
如果继续保存，将会覆盖云端的最新内容，本次上传已暂停。
· 建议选择刷新页面，查看云端最新内容后重新编辑（你这次的改动尚未上传）。
· 选择继续编辑可留在当前页面继续修改，稍后再次保存时仍会重新校验一次。
